# terraform-aws-platform

Terraformを使用してAWSインフラを構築し、Infrastructure as Codeの設計・実装・運用方法を学ぶためのリポジトリです。

## Goals

- Terraformの基本構文と実行フローを理解する
- AWSリソースをTerraformで構築する
- State、Module、Remote Backendを理解する
- GitHub Actionsを使用したTerraformの検証フローを構築する
- 実務経験をもとにしたAWSアーキテクチャをTerraformで再現する
